terraform init -> read the provider and download the provider
terraform plan -> it will check the syntax and understand what you are trying to do
terraform apply -> now it will apply the infra
terraform destroy -> delete the infra

terraform apply -auto-approve

terraform destroy -auto-approve

IaaC tools like terraform follows declarative way of creating infra

providers -> a plugin that let terraform to connect with platform API to CRUD the resources

terraform.tfvars -> this will be automatically conside

terraform plan/apply -var-file=dev.tfvars  (for other files we need to provide in cmd line like this)

environment variables:
export TF_VAR_instance_type="t3.micro"  - > ubuntu
set TF_VAR_instance_type="t3.micro"   -> windows

command line variables: 
terraform plan -var="instance_type=t3.medium"
